# Zones 0.7.2

Minor interface/layout revision of Zones 0.7.1.

## Changes

- Enlarged and constrained the Parameters panel so numeric spinners remain fully visible, including increment/decrement controls.
- Moved long parameter help text from numeric spinners to their labels, preventing truncated hover text over spinner arrow buttons.
- Removed hover text from the LPNR numeric control itself and attached the explanation to the `LPNR threshold` label.
- Reserved adequate width for the detector selector and removed incidental hover text from the combo box.
- Original C4D and Corrected C4D plots now receive equal vertical weight when both are visible.
- Updated application, launcher, documentation, export metadata and citation metadata to version 0.7.2.

Scientific processing is unchanged from Zones 0.7.1.
