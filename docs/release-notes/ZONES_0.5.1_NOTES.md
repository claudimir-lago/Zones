# Zones 0.5.1

Maintenance release following the 0.5.0 candidate.

- Fixed filled peak-area rendering in the Mobility domain by ordering the transformed x coordinates used by the area renderer.
- Corrected the About/User manual link to the repository `USER_GUIDE.html` and changed README guidance to open a rendered HTML preview rather than GitHub source view.
- Quantitation now reports migration time in seconds to 0.001 s.
- Time-domain FWHM is displayed to 0.001 s.
- Mobility position and FWHM are displayed to 0.01 Ti.
- Charge-domain position and FWHM retain the existing general numeric formatting.
- Updated project metadata to version 0.5.1.
