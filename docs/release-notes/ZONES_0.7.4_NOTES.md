# Zones 0.7.4

Corrective UI release.

- Domain coloring is now opt-in for application-owned buttons only.
- FlatLaf internal controls, including JSpinner increment/decrement buttons and JComboBox arrow buttons, are no longer recolored by `DomainTheme`.
- This fixes the hover-time visual deformation/artifacts seen on numeric spinners and combo boxes while preserving the Time/Charge/Mobility tint on Zones buttons.
- Scientific processing is unchanged from 0.7.3.
