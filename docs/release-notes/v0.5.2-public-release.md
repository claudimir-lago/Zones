# Zones 0.5.2

Changes since the previous public release, v0.2.0:

- Preserve signed charge and mobility values, with an explicit charge-axis inversion option and three mobility-calibration modes. Mobility references can be assigned directly in Quantitation.
- Show baseline scales in seconds and retain processing settings between sessions. Highlight fits with R² < 0.99 for inspection.
- Identify detectors as 1st C4D and 2nd C4D by migration order. Add an About dialog and a Windows launcher that does not keep a console open.
- Fix filled peak areas in the Mobility view and local user-manual access. Provide a GitHub-readable Markdown guide and an offline HTML guide.
- Format migration position and FWHM using local sampling resolution. Migration time is in minutes; time-domain FWHM remains in seconds.

GPL-3.0-or-later and third-party notices are retained. The Windows portable package includes Java 17.

Validation: Maven verify passed (36 tests reported, 26 passed and 10 skipped by the existing suite).

Full comparison: https://github.com/claudimir-lago/Zones/compare/v0.2.0...v0.5.2
