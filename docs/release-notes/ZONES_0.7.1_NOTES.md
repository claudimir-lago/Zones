# Zones 0.7.1

Usability revision of Zones 0.7.0.

- User export can now be saved either as a ZIP archive or as individual uncompressed files in a selected folder. All `.csv` files remain TAB-delimited.
- Peak-analysis progress/status text is larger, bold, and highlighted while fitting is running.
- Simplified button labels: Open, Analyze peaks, Export results, Mobility calibration, About, and Analyze / refit.
- Baseline stiffness is labeled `log(λ)` and the slider/spinner are grouped more tightly with the label.
- `num_std` is now presented as `FABC threshold (σ)` with user-oriented help text.
- The Mobility calibration dialog was made more compact horizontally.
- Scientific processing is unchanged from 0.7.0.
