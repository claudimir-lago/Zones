# Zones 0.5.0

Candidate release for GitHub publication.

## User-interface changes

- Detector labels now use **1st C4D** and **2nd C4D**, defined by order from the injection point rather than physical left/right placement.
- Added an **About…** dialog with the installed version, GitHub repository, user manual, main scientific reference, and GPL-3.0-or-later information.
- Added `docs/USER_MANUAL.md`.
- Renamed the Windows launcher to `start_Zones.cmd`.
- The Windows launcher uses `javaw` through `start`, so the command-prompt window does not remain open after Zones starts.

## Metadata

- Updated project version to 0.5.0.
- Added the official GitHub repository URL to Maven and CITATION metadata.

All scientific processing and analysis behavior from Zones 0.4.0 is preserved.
