# Zones 0.7.3

Maintenance release focused on parameter-control usability.

- Reworked the parameter rows so numeric spinners retain a dedicated fixed-width column and their increment/decrement buttons remain accessible.
- Increased the parameter panel minimum/preferred width to avoid compression.
- Removed tooltip handling from spinner subcomponents, the detector selector, and the LPNR threshold spinner to eliminate truncated hover artefacts.
- Preserved the equal-height Original C4D and Corrected C4D layout introduced in 0.7.2.
- Scientific processing is unchanged from 0.7.2.
