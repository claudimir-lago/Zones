Zones User Guide

From an electropherogram to baseline-corrected signals and peak metrics in time, charge and calibrated mobility coordinates.

1. Start Zones

The Windows x64 portable package includes Java and the required libraries. You do not need to install Java, Maven or an IDE.

  1. Download Zones-0.2.0-windows-x64.zip from the official release page.
  2. Use Extract All to extract the entire ZIP into a folder you can write to.
  3. Open the extracted folder and double-click Zones.exe. Keep the app and runtime folders next to it.
  4. Click Open .dat… and choose an electropherogram.
  5. Check the detector, set the analysis range, then click Calculate baseline.
  6. Inspect the corrected signal and click Analyze peaks…. Review the fits before exporting.

This is a Windows x64 package; it is not a macOS, Linux or native ARM package. A display of at least 1000 × 680 pixels is advisable. The analysis runs locally; no account or internet connection is needed to process data.

To update, extract the new release into a new folder. Keep your original data and exported results separately. To remove a portable copy, close it and delete its extracted folder after preserving any files you saved there.

2. Input files and detector selection

Zones detects the format from the first nonblank row. Files must contain numeric data without a column-heading row, finite numbers and strictly increasing time values. Use a decimal point.

FormatColumns, in orderSeparator
minimalistiCETime (min), left C4D, right C4D, current (µA), stored charge (mC)Whitespace, including tabs
oldMinimalistiCETime (min), left C4D, right C4DWhitespace or commas; commas are field separators, not decimal separators

The varying right C4D channel is selected by default. If it is constant, Zones selects the left channel when available. Use Detector to change channels. A constant selected channel cannot be processed. Changing the detector discards the current calculated result.

Three-column files do not contain current or charge, so Charge and Mobility are unavailable. Original input files are read without being overwritten.

3. Select the analysis range and calculate a baseline

Start in Time. Drag the two Analysis start/end markers to include the useful part of the experiment and exclude corrupted regions. They initially cover the full run. Baseline correction, detection and fitting use the selected time range.

Drag on the chart to zoom, use the mouse wheel to zoom, and Ctrl + drag to pan. Reset zoom restores the view. Changing the analysis range or processing parameters invalidates the calculated result: calculate the baseline again before analyzing peaks.

Click Calculate baseline. Inspect Original C4D, Corrected C4D and FABC anchors (magenta). The diagnostic area reports the sampling interval, noise estimate, generated scales and any failed scales. A completed calculation can still contain scale failures; inspect those diagnostics before accepting results.

Processing controls

Open Parameters. Start with the defaults, change one control at a time and click Recalculate. Hover over controls for explanations. Restore defaults restores the processing controls.

ControlMeaning and practical use
Enable selective MMR; Characteristic duration (s)Detects moving-median residual outliers above 5 robust sigma. Candidate runs are reconstructed using two neighboring samples on each side. Other samples are preserved; this is not a median filter applied to the entire signal. The duration determines the median window.
num_stdFABC baseline/peak classification threshold, from 2.0 to 3.5; default 3.0. Higher values tend to accept more baseline points. This is not an LOD or LOQ threshold.
Minimum baseline (s)Minimum duration of a baseline run.
Minimum/Maximum peak width (s); Number of scalesWidth range and requested number of multiscale FABC scales. Durations are converted to points using the median sampling interval. Duplicate rounded scales are removed.
K (votes)Number of scales that must classify a point as a peak region. K cannot exceed the effective number of unique scales.
Baseline stiffness — log10(lambda)From 5 to 15. Higher values give a stiffer baseline; lower values allow more flexibility. A setting of 9 means lambda = 10⁹.
Recalculate charge from currentProduces a recalculated charge trace after preprocessing using trapezoidal integration; stored charge is preserved. Independently, domain transformations prefer integrating the available current over using stored charge.
Details in pointsShows the conversion from physical durations to sample counts. Local anchor recovery is disabled in this pipeline.

4. Time, Charge and Mobility

Processing stays in time. Switching domains changes the plotted coordinate and domain-specific quantitation. It does not repeat peak detection or fitting directly in charge or mobility coordinates.
DomainCoordinate and requirements
TimeAcquisition time in minutes. Fitted widths and areas use seconds as indicated in column headings.
ChargeCharge magnitude |q| in mC. Current is integrated by the trapezoidal rule at the recorded sample times, with initial charge zero; stored charge is used only when current is absent. Signed charge remains internal.
MobilityMagnitude |µ| in Ti, where 1 Ti = 10⁻⁹ m² V⁻¹ s⁻¹. Requires charge and a two-standard calibration. Values above 1000 Ti and values near the zero-charge singularity are excluded.

Two-standard mobility calibration

  1. Identify two standards and determine their migration-charge magnitudes in mC for the same run and charge origin used in the analysis.
  2. Choose Mobility calibration…, or select Mobility when no calibration exists.
  3. Enter each standard's migration |q| (mC) and known effective mobility (Ti). Use a decimal point.
  4. Confirm the dialog and inspect the reported calibration coefficient and EOF term.

The implementation calculates k = (µ₁ − µ₂) / (1/q₁ − 1/q₂), µEOF = k/q₁ − µ₁, and µ = k/|q| − µEOF, then displays |µ|. It therefore implements a calibrated effective-mobility transformation with an EOF offset, rather than an uncorrected apparent-mobility scale. Its physical interpretation depends on valid standards and experimental assumptions.

Reference charges must be nonzero and have different magnitudes; all entries must be finite and define a nonzero k. Opening a new file clears the calibration. Record calibration values separately: the detailed ZIP export does not currently include them.

Range and polarity matter. Integration begins at zero for the data supplied to a calculation. Processing a cropped range can change the charge origin. Recheck calibration after changing the range. Current polarity reversal can make |q| non-monotonic; heed the warning. Folded or non-monotonic transformed peak coordinates are reported as unavailable where appropriate.

5. Peak analysis and interpretation

Analyze peaks… opens the peak-analysis window and starts detection and HVL fitting. LPNR is local prominence divided by local noise sigma. Its default threshold is 10; increasing it selects fewer candidates. LPNR is not analytical signal-to-noise ratio, LOD or LOQ. The initial candidate pool also has a fixed minimum prominence of 30 signal units in this version. Signals scaled below that threshold can yield no candidates even with a low LPNR threshold.

The Quantitation table is the primary result table for the selected domain. Positions, fitted-component areas and FWHM follow the domain's units. Charge areas have units a.u.·mC; mobility areas have units a.u.·Ti. These transformed areas are numerical integrals of fitted components, not concentration values.

Use Plates (N), Gaussian plates (NGau) and Fit details to show additional columns. Plate counts remain descriptors of the time-domain fit, including in transformed views.

Inspect component and window diagnostics, fit status, convergence, R², RMS and parameter bounds. A converged optimizer or high R² alone does not establish that a fit is reliable. Unreliable fit values are diagnostic only. Double-click a quantitation, component-result or window row to zoom to its fitted window. Overlay controls show fitted components, their sum and markers.

Changing a window's component count requests a refit and marks it as user edited. Document manual edits and retain the original data when reporting results.

6. Export and preserve your work

  • Export table… saves the Quantitation table as TAB-separated text (default Zones-quantitation.tsv). Choose a point or comma decimal separator. Export separately for each domain you need.
  • Export ZIP… saves metadata.txt, candidates.csv, components.csv, windows.csv and signal.csv. It records time-domain processing and fit diagnostics.
The detailed ZIP is not a saved session and does not contain the active-domain Quantitation table or mobility-calibration inputs. Save the TSV, calibration values, input data, selected range and program version together. Zones 0.2.0 has no project/session reopening workflow.

Use new export filenames to preserve earlier results. Keep filenames meaningful, for example including sample, detector, domain and analysis date.

7. Troubleshooting

SymptomWhat to check
The program does not startExtract the whole archive before starting Zones.exe. Keep app and runtime together. Use Windows x64. Do not substitute an old Java installation for the bundled runtime.
Windows displays a publisher warningThe portable executable is not code signed. Verify that the archive came from the official release and compare its SHA-256 with the published checksum. Follow your organization's software policy.
File cannot be readCheck the reported line and column, column count, decimal point, numeric values and strictly increasing times. Remove column headings from a working copy, preserving the original.
Calculate baseline is unavailableLoad a file and select a varying detector channel.
Analyze peaks is unavailableCalculate the baseline again after changing parameters, range or detector.
Charge or Mobility is unavailableCheck whether the input includes current/charge. Three-column files do not. Mobility also requires valid calibration.
No peaks, implausible peaks or distorted baselineCheck detector and range, inspect the original signal, review peak widths, stiffness and LPNR. Do not force a result by reducing thresholds without checking the data.
Mobility points or metrics are missingCheck the 1000 Ti limit, near-zero charge, polarity reversal, local monotonicity and calibration units.

Report reproducible problems at GitHub Issues. Include the version, operating system, processing settings and error text. Share experimental files only when you have permission to do so.

8. Scientific scope and licensing

Zones derives from jBaseline 0.2.2. Its pipeline uses selective MMR outlier processing, multiscale FABC baseline correction, peak detection, peak-window construction and Haarhoff–Van der Linde fitting. Quantitative results require scientific review; the application does not automatically identify compounds or establish concentration calibration, LOD or LOQ.

Scientific reference: E. T. da Costa, D. R. Oliveira and C. L. do Lago, “Qualitative and quantitative aspects of time-, charge-, and mobility-based electropherograms,” Electrophoresis 43 (2022), 2363–2376. DOI: 10.1002/elps.202200195. Zones uses trapezoidal charge integration.
